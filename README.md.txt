# News Authenticity Classification using NLP & Machine Learning

A machine learning project for classifying news articles as real or fake using Natural Language Processing (NLP) techniques.

## Project Highlights

- Analyzed nearly 45K news articles
- Performed regex-based text preprocessing
- Converted text into numerical features using TF-IDF Vectorization
- Compared 4 machine learning classifiers
- Achieved 99.6% best test accuracy
- Built an inference pipeline for classifying unseen news articles

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Gradient Boosting Classifier
- Random Forest Classifier

## Tech Stack

Python | Pandas | Scikit-learn | NLP | TF-IDF | Matplotlib
